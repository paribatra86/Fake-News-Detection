# Fake news Detection 

The objective of this project is to build a basic classification model
capable of distinguishing between real and fake news articles.

## Dataset

The dataset contains two categories of news:
- Real News
- Fake News

You can download it from Kaggle . 

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Feature Preparation
6. Model Training
7. Model Evaluation

## Key Features

- Data preprocessing and cleaning
- Exploratory data analysis
